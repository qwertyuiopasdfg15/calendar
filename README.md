# 🎙️ 智能语音日历系统

一个支持语音输入、AI智能解析、多命令批量处理的智能日历管理系统。



## ✨ 主要功能

### 核心能力
- 🎤 **语音控制**：点击麦克风按钮说话，自动识别并执行命令
- 🧠 **AI智能解析**：使用百炼大模型理解自然语言，无需学习特定格式
- 🔄 **多命令批量处理**：一句话可包含多个操作，自动拆分依次执行
- 🔔 **灵活提醒设置**：支持当日0点提醒，特定时间提醒，截止日前3天每日提醒三种提醒方式
- 📅 **可视化日历**：30天日历网格，直观查看所有事项
### 支持的操作
| 操作 | 说明 | 示例 |
|------|------|------|
| 添加待办 | 在指定日期添加事项 | `1号下午3点开会` |
| 删除待办 | 删除指定事项 | `删除1号的买水果` |
| 查看待办 | 查看某天所有事项 | `查看5号` |
| 清空调日 | 清空某天所有事项 | `清空28号` |
| 修改时间 | 更改事项的时间 | `把1号的会改成下午4点` |



## 📁 文件结构
```
calendar/
├── data_stracture.py          # 数据结构（Thing, Day, Month）
├── bai_lian_nlp_parser.py     # AI自然语言解析器，引入百炼大模型
├── voice_calendar.py          # 主程序（语音日历）
└── enhanced_calendar.py       # 增强版（支持提醒设置，推荐）
```



## 🚀 快速开始
下载tag中的第一版本
### 环境要求
- Python 3.8+
- 网络连接（用于AI解析和语音识别）
### 安装依赖
```bash
pip install sounddevice scipy SpeechRecognition numpy requests
```
### 配置API Key
编辑 `bai_lian_nlp_parser.py`，填入你的百炼API Key：
如果没有API Key，系统会自动切换到本地规则解析器（功能严重受限）
### 运行程序
**基础版**（语音控制 + 多命令）：
```bash
python voice_calendar.py
```
**增强版**（含提醒设置功能，推荐）：
```bash
python enhanced_calendar.py
```



## 📝 使用示例
### 语音输入
1. 点击绿色麦克风按钮
2. 说话（如"帮我安排一下这月的工作：1号下午3点开项目启动会，5号上午10点做需求，
10号截止交设计方案要提前3天提醒我，然后帮我把3号的健身删掉，再看看15号有什么安排"）
3. 再次点击按钮停止录音
4. 系统自动识别并执行
### 文字输入
直接在输入框输入命令，按回车或点击"执行"




## 🎯 智能特性
### 自然语言理解
- 自动识别"明天"、"后天"、"今天"等相对日期（默认今天是一号）
- 理解"下午3点"、"晚上7点"等时间表达
- 识别"帮我记一下"、"提醒我"、"别忘了"等口语
### 多命令拆分
- 支持逗号、句号、"然后"、"以及"等连接词
- 自动拆分成独立操作，依次执行
- 显示执行结果汇总
### 容错处理
- AI解析失败时自动切换到规则解析
- 删除操作多个匹配时弹出选择框
- 网络异常时本地规则兜底

## 🔧 常见问题
### 1. 语音功能不可用
```bash
# 安装依赖
pip install sounddevice scipy SpeechRecognition numpy
```
### 2. 麦克风测试失败
- Windows：检查系统麦克风权限
- macOS：系统设置 → 隐私与安全性 → 麦克风
- Linux：安装 `pulseaudio` 或 `alsa-utils`
### 3. AI解析失败
- 检查API Key是否正确
- 检查网络连接
- 系统会自动切换到本地规则解析器
### 4. 文件命名冲突
- 不要将程序命名为 `calendar.py`（与Python标准库冲突）
- 推荐使用 `voice_calendar.py` 或 `enhanced_calendar.py`
